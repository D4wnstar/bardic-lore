# Discontinued
Bardic Lore was an experiment in using Tauri and SvelteKit to make a tool that I needed in practice, which was to organize a large collection of music with tags for ease of access on the fly, along with playing multiple tracks over each other and over Discord. It was born from the limitations of [kenku-fm](https://github.com/owlbear-rodeo/kenku-fm), which I was using at the time. While the need stayed, Bardic Lore never made it out of early development due to Tauri being a rather high-maintenance stack that required more skills than I had at the time, so it remained an experiment in user data organization, desktop UI/UX and Discord bots.

Bardic Lore has a spiritual successor called [Soundweave](https://github.com/D4wnstar/soundweave). This repo is left here as a public archive for future reference.
